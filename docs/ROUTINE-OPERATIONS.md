## Bulk import and accumulator pool

Upload only an export whose terms permit private analysis. CSV <=64 KiB, 1–100 source rows, up to 200 expanded paired propositions. Required evidence includes player identity/name, canonical market, actual line, price(s), bookmaker, timezone-qualified quote timestamp, source and the supported verified settlement rule. Exact game/player IDs are optional only when name/team/market resolve uniquely. `over_odds`/`under_odds`, `odds_format` (`decimal`, `american`, `fractional`) and `line_type` (`primary`, `alternate`, `unspecified`) are supported. Ambiguity rejects the import; no missing values are invented. Quotes expire after the existing 30-minute limit.

The accumulator pool retains eligible alternative lines; it never forces the whole Top 2 list into one ticket. Cross-player dependence remains unvalidated: joint probability/EV withheld, probability bounds shown. Exact intersections are available only for thresholds on the same player/stat/forecast distribution. Combined-price evidence must be actually available for those exact legs; multiplying singles odds is not a bookmaker quote. No seasonal success estimate is claimed from synthetic thresholds or assumed independence.
